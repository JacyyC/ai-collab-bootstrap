# Framework

Framework 保存技术事实和已接受目标，不记录实时进度。默认 [Current](current/v1.md) 使用一页；内容增长后按职责拆分并链接，空的技术/组件/流程页面不预建。

[Target](target/v1.md) 是可选目标骨架。只有产生已接受架构差异时采用；[长期决策](../decisions/README.md)和[Roadmap](../ROADMAP.md)同样按需要建立。当前骨架尚未登记业务实现，不代表任何产品能力。

Current 的事实必须能连回代码、配置、测试或运行证据。Target 写剩余差异、依赖和采用门槛；实施中未验证的内容留在工作项。详细路由见 [Policy](../DOCUMENTATION_POLICY.md)。
